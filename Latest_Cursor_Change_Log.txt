### Key Implementation Details:

**Authentication State:**
- Uses `useAuth()` hook to get `user`, `logout`, and `isAuthenticated`
- Conditionally renders UI based on authentication status

**Logout Functionality:**
- Calls `logout()` from AuthContext which:
  - Removes user from localStorage
  - Clears user state
  - Navigates to login page

**User Display:**
- Shows username from `user.username`
- Displays "Welcome, <username>" when logged in
- Shows "Not logged in" when not authenticated

**Navigation Logic:**
- Authenticated users see: Home, Dashboard, Add Emission
- Non-authenticated users see: Home, Login, Register
- All users see the welcome/logout section (with appropriate content)
