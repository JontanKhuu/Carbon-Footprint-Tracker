# Latest Changes Log

## Date: 2025-12-08
## Task: Fixed automatic emission factor calculation issues

### What I Did:
Fixed issues where CO2 fields were showing as required even for supported activities, and improved the auto-calculation logic to ensure values are always set correctly.

### Step-by-Step Process:

#### 1. Fixed Form Validation
- **File modified:** `frontend/src/pages/AddEmission.tsx`
- **Changes:**
  - Added `noValidate` attribute to form element to disable HTML5 validation
  - Made `required` attribute conditional: `required={!activitySupported}`
  - This prevents browser from validating hidden fields

#### 2. Improved Conditional Field Rendering
- **Change:** Updated condition for showing CO2 input fields
- **New condition:** Fields only show when:
  - Emission factors have loaded (`!isLoadingFactors && Object.keys(emissionFactors).length > 0`)
  - Category and activity are selected
  - Activity is NOT supported (`!activitySupported`)
- **Result:** Fields are completely hidden (not in DOM) for supported activities

#### 3. Enhanced Auto-Calculation Logic
- **Change:** Updated useEffect to always calculate CO2 when factor exists
- **Previous:** Only calculated if `amount > 0`
- **New:** Calculates even if amount is 0 (shows 0.00)
- **Benefit:** Values are always set, preventing validation errors

#### 4. Improved Activity Support Check
- **Change:** Updated `isActivitySupported()` to check if factors have loaded
- **Logic:** Returns false if emission factors haven't loaded yet
- **Result:** Prevents false positives when factors are still loading

#### 5. Fixed Value Handling
- **Change:** Updated input value handling to use `!== undefined` check
- **Previous:** `value={formData.co2_equivalent || ''}` (0 would show as empty)
- **New:** `value={formData.co2_equivalent !== undefined ? formData.co2_equivalent : ''}`
- **Result:** Properly handles 0 values

### Files Modified:
1. `frontend/src/pages/AddEmission.tsx` - Fixed validation and conditional rendering

### Key Fixes:

**HTML5 Validation Issue:**
- Problem: Browser was validating `required` fields even when hidden
- Solution: Added `noValidate` to form, made `required` conditional
- Result: Only custom validation runs, not browser validation

**Field Visibility Issue:**
- Problem: Fields might show before emission factors load
- Solution: Added check for `!isLoadingFactors && Object.keys(emissionFactors).length > 0`
- Result: Fields only show when truly needed

**Auto-Calculation Issue:**
- Problem: Values might not be set if amount is 0
- Solution: Always calculate when factor exists, even if amount is 0
- Result: Values are always set for supported activities

**Value Display Issue:**
- Problem: 0 values showing as empty string
- Solution: Use `!== undefined` check instead of `|| ''`
- Result: 0 values display correctly
