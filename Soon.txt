Unused API Routes - To Decide Later
====================================

These API routes are implemented in the backend but are never called from the frontend:

USER ROUTES:
------------
1. GET /api/users
   - Backend: get_users() in backend/app/routes/users.py
   - Frontend: getUsers() function exists in frontend/src/services/api.ts but is never imported or called
   - Purpose: Get all users
   - Status: Defined but unused

2. GET /api/users/<id>
   - Backend: get_user(user_id) in backend/app/routes/users.py
   - Frontend: No API function exists
   - Purpose: Get a specific user by ID
   - Status: Not accessible from frontend

3. PUT /api/users/<id>
   - Backend: update_user(user_id) in backend/app/routes/users.py
   - Frontend: No API function exists
   - Purpose: Update user (username, email, password)
   - Status: Not accessible from frontend

4. DELETE /api/users/<id>
   - Backend: delete_user(user_id) in backend/app/routes/users.py
   - Frontend: No API function exists
   - Purpose: Delete a user
   - Status: Not accessible from frontend
